# agent-ops-platform
项目背景与目标：面向故障调查和发布前检查，开发智能运维辅助平台，关联运行资料、变更与历史经验，生成附证据来源的报告，并通过统一网页简化任务提交和人工复核。
核心职责一：设计研判、诊断、处置复盘三类角色及8项受限技能，结合权限、预算和引用检查，生成观测事实、候选原因及建议。
核心职责二：通过FastMCP接入7个只读取证工具，用LangChain组织结构化模型分析，用LangGraph实现五节点评审和人工暂停，再通过SQLite检查点支持恢复。
核心职责三：实现独立风险规则、人工意见绑定、记录补写，以及可选Redis缓存、锁和任务消息协调；开发网页提供后台任务、日志、报告下载和人工复核入口。
项目成果：完成故障单角色和发布safe案例的真实模型验证；发布评审74项测试通过、1项受环境限制跳过，工作台22项全部通过；完成4类网页接口离线联调，确认阅读不会覆盖容量阻断。
